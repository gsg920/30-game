# 🎰 Royal Casino

웹 브라우저에서 즐길 수 있는 카지노 미니게임 프로젝트입니다.

## 📌 프로젝트 소개

블랙잭, 룰렛, 텍사스 홀덤을 플레이하고, 베팅을 통해 자산을 늘리거나 잃을 수 있는 카지노 게임입니다. 보유 자산과 소지품에 따라 다양한 엔딩을 경험할 수 있습니다.

## 🎮 주요 기능

- **블랙잭**: 카드 게임 및 베팅 (히트/스탠드/더블다운, 딜러 AI)
- **룰렛**: 다양한 베팅 방식 지원 (스트레이트, 컬러, 홀짝, 다스 등)
- **텍사스 홀덤**: 정규 포커 족보 판정, 배율 레이즈, 밸런스형 올인 조건 및 지능형 NPC AI
- **자산 관리**: 게임별 베팅과 잔액 관리
- **소지품 시스템**: 아이템 구매 및 전당포 판매
- **엔딩 시스템**: 잔액과 소지품에 따른 다채로운 귀가 엔딩
- **파산 및 재시작**: 파산 처리와 초기 상태 복구

## 🛠️ 기술 스택

- HTML
- CSS (Tailwind CSS)
- JavaScript (Vanilla JS, Web Audio API)

## 🚀 실행 방법

1. 저장소를 클론하거나 프로젝트 파일을 다운로드합니다.
2. `index.html` 파일을 웹 브라우저에서 바로 실행하거나, `node server.js`로 로컬 서버를 구동하여 즐기실 수 있습니다.
