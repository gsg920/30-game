# 🎰 Royal Casino

웹 브라우저에서 즐길 수 있는 카지노 미니게임 프로젝트입니다.

## 📌 프로젝트 소개

블랙잭, 룰렛, 텍사스 홀덤을 플레이하고, 베팅을 통해 자산을 늘리거나 잃을 수 있는 카지노 게임입니다. 보유 자산과 소지품에 따라 다양한 엔딩을 경험할 수 있습니다.

## 🎮 주요 기능

- **블랙잭**: 카드 게임 및 베팅
- **룰렛**: 다양한 베팅 방식 지원
- **텍사스 홀덤**: 포커 게임 및 베팅
- **자산 관리**: 게임별 베팅과 잔액 관리
- **소지품 시스템**: 아이템 구매 및 전당포 판매
- **엔딩 시스템**: 잔액과 소지품에 따른 귀가 엔딩
- **파산 및 재시작**: 파산 처리와 초기 상태 복구

## 🛠️ 기술 스택

- HTML
- CSS
- JavaScript

## 🚀 실행 방법

1. 저장소를 클론하거나 프로젝트 파일을 다운로드합니다.
2. `index.html` 파일을 웹 브라우저에서 실행합니다.

별도의 서버 설치 없이 실행할 수 있습니다.

- 새로운 엔딩 및 아이템 추가
- UI와 애니메이션 개선
- 게임 진행 및 베팅 시스템 개선
