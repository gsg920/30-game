## 🎮 게임 모드 소개

### 1. 🃏 텍사스 홀덤 (Texas Hold'em Poker)
최대 4명의 개성 있는 NPC(김철수, 이지은, 박민수, 제시카)와 심리전을 벌이는 정통 포커입니다.
* **정밀 족보 엔진**: 플레이어 패 2장과 커뮤니티 카드 5장 중 최상의 5장을 조합하여 하이카드부터 스트레이트 플러시까지 자동 판정합니다.
* **올인 레이즈 (All-In Raise)**: 별도의 올인 버튼 없이, 레이즈 인상폭에서 `ALL IN`을 고르고 `RAISE`를 누르면 남은 잔액 전부를 거는 올인 레이즈가 됩니다. 잔액이 선택한 인상폭에 모자랄 때도 `RAISE`는 남은 잔액 전부를 거는 올인이 되며, 잔액을 모두 걸면 남은 카드가 오픈되며 쇼다운으로 이어집니다.
* **배율 레이즈 (Dynamic Raise)**: 시작 배팅액에 비례하는 배율 버튼(`+1x`, `+2x`, `+3x`, `+5x`)을 제공하여 소액 판과 고액 판 모두에서 자연스러운 베팅이 가능합니다. NPC의 베팅도 시작 배팅액을 기준으로 하며 플레이어의 남은 잔액을 넘지 않습니다.
* **지능형 NPC AI**: NPC는 자신의 패로 추정한 승률(몬테카를로 시뮬레이션)과 팟 오즈를 비교해 콜과 폴드를 결정하고, 성격(타이트/루스)에 따라 판단 기준이 조금씩 다릅니다.

### 2. ♠️ 블랙잭 (Blackjack)
딜러와의 승부이며, 같은 테이블에 NPC를 최대 4명까지 앉힐 수 있습니다. 매 라운드 새 덱으로 진행됩니다.
* **기본 룰**: 21에 가장 가까운 패를 완성하면 승리하며, 처음 2장이 21이면 3:2 배당(베팅액의 1.5배 수익)의 블랙잭 승리! 딜러도 블랙잭이면 무승부(Push)로 환급됩니다. (스플릿, 인슈어런스는 지원하지 않습니다.)
* **다양한 액션**:
  * `HIT`: 카드 한 장 더 받기
  * `STAND`: 현재 점수로 차례 마치기
  * `DOUBLE`: 처음 받은 2장일 때 추가 베팅으로 베팅액을 2배로 올리고 단 한 장의 카드만 더 받은 뒤 자동으로 스탠드 (잔액이 베팅액 이상일 때만 가능)
* **딜러 AI**: 16 이하에서는 무조건 Hit, 17 이상에서는 무조건 Stand 규칙을 철저히 준수합니다. 플레이어가 버스트하거나 블랙잭이면 카드를 더 뽑지 않습니다.

### 3. 🎡 유러피언 룰렛 (European Roulette)
0부터 36까지 총 37개 숫자로 이루어진 클래식 싱글 제로 룰렛입니다.
* **부드러운 캔버스 스핀 애니메이션**: 실제 카지노 휠 회전 연출과 서스펜스 사운드 제공.
* **다채로운 베팅 구역 지원** (배당은 원금 포함 지급액 기준):
  * **단일 번호 (Straight Up)**: 36배 배당
  * **색상 (Red / Black)**: 2배 배당
  * **홀짝 (Odd / Even)**: 2배 배당
  * **대소 (1-18 / 19-36)**: 2배 배당
  * **더즌 (1-12 / 13-24 / 25-36)**: 3배 배당
  * 0이 나오면 단일 번호 베팅을 제외한 모든 베팅이 낙첨됩니다.

카지노 상단의 **전당포**에서 돈을 모아 빼앗긴 물건을 되찾을 수 있습니다. 잔액이 $10 미만으로 떨어지면 보유 물건이 비싼 순서대로 자동으로 강제 매각되어 잔액이 보충됩니다 (직접 되파는 기능은 없습니다).

| 📱 **스마트폰** | **$10,000** | $6,000 | 콜택시 호출 가능 |

### 🎬 다양한 엔딩 분기
엔딩과 파산 화면에는 각각 일러스트가 표시됩니다. (`images/endings/`)

* 👑 **전설의 하이롤러**: 잔액 $100,000 이상 + 모든 소지품(옷, 지갑, 폰, 차) 회수 성공. VIP 대접을 받으며 당당히 퇴장!
* 🚷 **블랙리스트 (숨겨진 엔딩)**: 하이롤러 조건을 채웠는데 누적 승리금(이긴 판의 이익 합계)이 $500,000 이상이면, 너무 많이 딴 손님으로 찍혀 카지노 입장 금지 명단에 오릅니다.
* 🚗 **내 차로 귀가**: 옷과 자동차를 되찾고 당당하게 전용 차량으로 퇴장.
* 🚕 **택시를 타고 귀가**: 스마트폰과 옷을 되찾아 택시를 불러 편안하게 귀가.
* 🚌 **버스를 타고 귀가**: 옷은 되찾았지만 폰이나 차가 없어 대중교통으로 귀가.
* 🚶 **빈털터리 귀환**: 옷은 겨우 샀지만 남은 돈은 0원. 씁쓸한 귀가.
* 🚫 **아직 떠날 수 없다**: 옷조차 되찾지 못해 떠날 수 없음 (돈을 더 벌어 옷을 되찾아야 함).
* 💀 **파산(빈털터리의 최후)**: 잔액이 $10 미만으로 떨어지고 소지품을 강제 매각해도 $10 미만이면 카지노에서 쫓겨나며 처음부터 다시 시작.

## 🛠️ 기술 스택 (Tech Stack)

* **Frontend**: HTML5, CSS3, JavaScript (Vanilla ES6+)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) (로컬 빌드), Custom CSS Animations (카지노 펠트 텍스처, 네온/올인 이펙트)
* **PWA**: 웹 앱 매니페스트와 서비스 워커로 설치 및 오프라인 실행 지원
* **Audio**: Web Audio API (외부 음원 파일 없이 코드 기반 실시간 효과음 합성)
* **Fonts**: Noto Sans KR, Playfair Display (로컬 포함)
* **Icons**: FontAwesome 6.4 (로컬 포함)

> Tailwind 클래스를 추가하거나 바꾼 뒤에는 CSS를 다시 빌드합니다: `tailwindcss -c tailwind.config.js -i tailwind.input.css -o vendor/tailwind.css --minify` (v3 독립 실행 CLI). 캐시할 파일을 바꾸면 `sw.js`의 `CACHE_VERSION`도 올려 주세요.

## 🚀 로컬 실행 방법 (Local Setup)

별도의 패키지 설치 없이 누구나 즉시 실행할 수 있습니다.

### 방법 1. 브라우저로 직접 실행
1. 저장소를 클론하거나 ZIP 다운로드합니다.
   ```bash
   git clone https://github.com/gsg920/casino-game.git
   ```
2. 다운로드된 폴더의 `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)로 실행합니다.

### 방법 2. Node.js 로컬 서버 실행
프로젝트에 내장된 정적 웹 서버를 통해 실행할 수 있습니다.
```bash
# 로컬 웹 서버 시작 (포트: 3000)
node server.js
```
서버 실행 후 브라우저에서 **`http://localhost:3000`**으로 접속합니다.
