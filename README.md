## 🎮 게임 모드 소개

### 1. 🃏 텍사스 홀덤 (Texas Hold'em Poker)
최대 4명의 개성 있는 NPC(김철수, 이지은, 박민수, 제시카)와 심리전을 벌이는 정통 포커입니다.
* **정밀 족보 엔진**: 플레이어 패 2장과 커뮤니티 카드 5장 중 최상의 5장을 조합하여 하이카드부터 로얄 스트레이트 플러시까지 자동 판정합니다.
* **올인 밸런스 시스템 (All-In Rules)**:
  * 묻지마 올인 방지: 커뮤니티 카드가 오픈되는 **플랍(Flop) 이후 & 원페어 이상 족보** 보유 시에만 올인이 잠금 해제됩니다 (`🔥 ALL IN`).
  * 숏스택(위기) 구제: 잔액이 시작 배팅 대비 3배 이하이거나 $200 이하인 경우 생존을 위한 역전 긴급 올인이 가능합니다.
* **배율 레이즈 (Dynamic Raise)**: 시작 배팅액에 비례하는 배율 버튼(`+1x`, `+2x`, `+3x`, `+5x`)을 제공하여 소액 판과 고액 판 모두에서 자연스러운 베팅이 가능합니다.
* **지능형 NPC AI**: NPC도 본인의 패와 플레이어의 레이즈/올인 크기를 계산하여 무모한 기부 없이 전략적으로 콜과 폴드를 결정합니다.

### 2. ♠️ 블랙잭 (Blackjack)
딜러와의 1:1 카드 카운팅 & 확률 승부입니다.
* **정통 룰 준수**: 21에 가장 가까운 패를 완성하면 승리하며, 처음 2장이 21이면 1.5배 배당의 블랙잭 승리!
* **다양한 액션**:
  * `HIT`: 카드 한 장 더 받기
  * `STAND`: 현재 점수로 차례 마치기
  * `DOUBLE DOWN`: 승리를 확신할 때 베팅액을 2배로 올리고 단 한 장의 카드만 더 받기
* **딜러 AI**: 16 이하에서는 무조건 Hit, 17 이상에서는 무조건 Stand 규칙을 철저히 준수합니다.

### 3. 🎡 유러피언 룰렛 (European Roulette)
0부터 36까지 총 37개 숫자로 이루어진 클래식 싱글 제로 룰렛입니다.
* **부드러운 캔버스 스핀 애니메이션**: 실제 카지노 휠 회전 연출과 서스펜스 사운드 제공.
* **다채로운 베팅 구역 지원**:
  * **단일 번호 (Straight Up)**: 36배 배당
  * **색상 (Red / Black)**: 2배 배당
  * **홀짝 (Odd / Even)**: 2배 배당
  * **대소 (1-18 / 19-36)**: 2배 배당
  * **더즌 (1-12 / 13-24 / 25-36)**: 3배 배당

### 🎬 다양한 엔딩 분기
* 👑 **카지노의 왕**: 잔액 $100,000 이상 + 모든 소지품(옷, 지갑, 폰, 차) 회수 성공. 카지노의 전설로 등극!
* 🚗 **내 차로 귀가**: 옷과 자동차를 되찾고 당당하게 전용 차량으로 퇴장.
* 🚕 **택시를 타고 귀가**: 스마트폰과 옷을 되찾아 택시를 불러 편안하게 귀가.
* 🚌 **버스를 타고 귀가**: 옷은 되찾았지만 폰이나 차가 없어 대중교통으로 귀가.
* 🚶 **빈털터리 귀환**: 옷은 겨우 샀지만 남은 돈은 0원. 씁쓸한 귀가.
* 🚫 **아직 떠날 수 없다**: 옷조차 되찾지 못해 경비원에게 문전박대.

## 🚀 로컬 실행 방법 (Local Setup)

별도의 패키지 설치 없이 누구나 즉시 실행할 수 있습니다.

### 방법 1. 브라우저로 직접 실행
1. 저장소를 클론하거나 ZIP 다운로드합니다.
   ```bash
   git clone https://github.com/gsg920/casino-game.git
   ```
2. 다운로드된 폴더의 `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)로 실행합니다.

### 방법 2. Node.js 로컬 서버 실행
프로젝트에 내장된 정적 웹 서버를 통해 실행할 수 있습니다.
```bash
# 로컬 웹 서버 시작 (포트: 3000)
node server.js
```
서버 실행 후 브라우저에서 **`http://localhost:3000`**으로 접속합니다.
